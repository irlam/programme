(Optional) API utilities
Who am I (useful to check session):
https://programme.defecttracker.uk/api/auth.php?action=whoami

Login (POST JSON: { "email": "...", "password": "..." }):
https://programme.defecttracker.uk/api/auth.php?action=login

Logout (POST with X-CSRF):
https://programme.defecttracker.uk/api/auth.php?action=logout

Tip: add &debug=1 to API URLs if you need verbose errors while testing.
