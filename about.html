Programme – How it works

This tool manages apartment build sequences with automatic scheduling (working days, UK bank holidays), overlapping tasks (FS/SS with ± lag), tight handover flags, and quick exports for short-term programme packs.

Timezone: Europe/London • Calendar: Mon–Fri + UK bank holidays

Key concepts

  • Tasks have Contractor, Ops, Duration (working days), Start/Finish (calculated), optional constraint (Start No Earlier Than), and belong to an Apartment.
  • Dependencies: Finish→Start (FS) and Start→Start (SS) with positive or negative lag (days) to allow overlaps.
  • Recalculation: editing a duration, dependency, or constraint cascades through successors using working-day arithmetic.
  • Flags: “Tight handover” if the gap is < 1 working day; overlap warnings if two tasks collide in the same apartment/zone.

Everyday tasks

Add / edit tasks

  1. Open the Gantt or table view (Planner).
  2. Edit Ops, Duration, or add dependencies (FS/SS ± lag).
  3. Save – dates recalculated automatically; flags update.

Short-term programme

  1. Open /api/export/shortterm.php?project=1&days=14&group=apartment.
  2. Switch group: group=contractor. Use format=html for a quick web version.
  3. Print or share the generated PDF.

Templates & cloning

Create a sequence once, then clone it to multiple apartments.

  1. Snapshot an apartment at /admin/templates.php – “Create from apartment”.
  2. Preview tasks and dependencies; then “Clone to apartments”.
  3. Dates will calculate from the project start and dependencies.

Baselines & variance

  1. Capture a baseline at /admin/baselines.php.
  2. Variance compares current Start/Finish against the baseline in working days.

Exports

  • Short-term PDF (2–4 weeks): see above.
  • Sample block CSV: /api/export/csv.php?project=1&block=A&from=YYYY-MM-DD&to=YYYY-MM-DD. Open in Excel.

Full Excel with compact Gantt band is planned next; for now, CSV opens cleanly in Excel.

Accounts & roles

  • First user can be created at /admin/users.php. Afterwards, only Admins can create users.
  • Roles: Admin, Planner (edit), Commenter (view + comments), Viewer (read-only).

Troubleshooting

  • Append &debug=1 to API URLs to see detailed errors.
  • If PDF fails, ensure FPDF exists at /app/Lib/fpdf/fpdf.php.
  • If dates look odd, check dependencies (FS/SS) and lags.

Version: Build Pack 5 • UI is self-hosted, no external CDNs.
