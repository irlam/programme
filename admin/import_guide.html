Two easy ways to prepare files: a simple Task List (universal) or a 6-Week Lookahead grid. Download a template, edit offline, then upload on the Import page.

Download templates

Task List (.xlsx)

Best for most use cases. One row per task with optional dependencies (FS/SS + lag).

  • Columns: Block, Floor, Unit, Type, Task, Contractor, Ops, Duration (wd), Start, Finish, Zone, Predecessor, LinkType, LagDays, SNET, Notes.
  • Dates: dd/mm/yyyy or yyyy-mm-dd. Duration is working days.
  • Leave Start or Finish blank — the importer will compute from Duration where possible.

6-Week Lookahead (.xlsx)

Calendar grid view. Set the start date, then mark active day cells with “x”.

  • Safer than conditional formatting: put a small value in each active cell.
  • Importer reads rows and turns day runs into tasks with real dates.

Task List (CSV)

Spreadsheet-agnostic format. Same columns as the XLSX task list.

What other files will work?

Any XLSX/CSV that has a row-based task table will import. The importer recognises common headers and synonyms, e.g.:

  • Task (a.k.a Activity, Description)
  • Contractor (a.k.a Trade, Vendor)
  • Start (Start Date), Finish (End), Duration (wd)
  • Ops (Headcount), Zone (Area), Block/Floor/Unit/Type
  • Dependencies: Predecessor, LinkType (FS/SS), LagDays (±)

If headers are unusual, the preview will offer a quick column mapping step (you can save the mapping for next time).

Round-trip editing

  • Export Task list (.xlsx) from the Gantt, edit offline, then import — rows with an ID update; rows without an ID insert.
  • Optionally capture a baseline during import to track slippage in the Variance view.
